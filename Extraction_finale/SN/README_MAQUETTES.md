### Structure des fichiers

Les maquettes ont été découpées par niveau et par parcours selon la nomenclature suivante:

**Format:** `NiveauInitial_ParcoursInitiales.toml`

- **L1** : Licence 1 (Semestres 1-2)
- **L2** : Licence 2 (Semestres 3-4)
- **L3** : Licence 3 (Semestres 5-6)

#### Niveaux de Master
- **M1** : Master 1 (Semestres 1-2)
- **M2** : Master 2 (Semestres 3-4)

### Contenu des fichiers

Chaque fichier TOML contient :
- Les métadonnées du niveau (domaine, mention, spécialité, grade)
- Les Unités d'Enseignement (UE) organisées par catégorie :
  - UE de connaissances fondamentales
  - UE de méthodologie
  - UE de culture générale
  - UE de spécialité
- Les Éléments Constitutifs d'UE (ECUE) avec :
  - Code et intitulé
  - Masses horaires (CM, TD, TP, Projet)
  - Crédits
